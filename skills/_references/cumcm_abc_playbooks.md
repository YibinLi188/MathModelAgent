# 国赛 A/B/C 题差异化路线

本文件提供先验路线，不用题号替代题意。开始建模时先依据真实题面判定主导矛盾；若题目内容与历年常见分工不一致，以题面为准，并在分析报告中说明偏离原因。

## 共同底线

无论题型，先建立逐问输出契约：题目要求的对象、时刻、参数范围、场景、附件格式和精度必须逐项登记。代表性样例、整数时刻或单条轨迹不能代替完整要求。结论必须注明搜索域、信息边界和证据等级。

所有连续域事件均采用“粗筛定位 + 局部求根/优化 + 网格加密或独立复算”。全区间极值应包含端点，并检查多个彼此分离的候选峰；不能只精修粗网格最高的一个点。优化设计须区分固定条件、可变条件和候选族，候选族内无改进不能表述为全局不可改进。

## A 题：机理、连续系统与工程计算优先

常见对象包括几何运动、动力学、传热、波动、光学和工程装置。推荐主线为：几何/物理语义冻结，坐标和单位统一，守恒律或运动学方程推导，最小可行数值基线，连续事件与全构件审计，参数敏感性和工程边界验证。

A 题必须优先检查：受力或构件关系图是否足以复核方程；实体是否被错误简化为点或中心线；碰撞、接触、越界等事件是否在连续时间内防漏检；全体构件、全路径和全参数区间是否覆盖；题目指定的全部时刻和代表对象是否完整列表；固定端点、固定轨迹等条件是否被误写成对更大设计域的结论。

图表以解释机理和验证方程为目的，通常包括一张坐标/构件示意、一张关键状态或轨迹图，以及必要的误差、间隙或速度响应图。颜色只编码有意义的类别；最终须能在灰度打印中辨认。

## B 题：离散结构、运筹优化与算法验证优先

常见对象包括路径、调度、网络、布局、搜索和组合决策。推荐主线为：决策变量与约束语义冻结，可行基线，精确模型或可证下界，候选算法，约束逐项回放，多初值/多预算稳定性，以及最优性证据分级。

B 题必须优先检查：是否只找到可行点却声称最优；时间或节点上限下的 incumbent 是否披露 gap；滚动计划是否逐期守恒并满足前缀约束；离散候选、固定航向或人工分区是否限制了最优性范围；启发式结果是否与简单基线、精确小规模实例或下界比较；官方结果模板是否逐格回写并保持结构。

图表以解释结构与权衡为目的，优先使用网络/路径示意、甘特图、帕累托前沿、收敛或最优性 gap 曲线和约束裕度图。禁止用装饰性流程图代替结果证据。

## C 题：数据质量、统计推断与决策稳健性优先

常见对象包括多源表格、预测、评价、分类、聚类、时间序列和数据驱动决策。推荐主线为：数据字典与质量审计，观测单位和零值语义冻结，时间/实体分组切分，可解释基线，候选模型，外部或留出验证，不确定性与决策敏感性。

C 题必须优先检查：训练与验证是否泄露；缺失、结构零、非检出零和闭合数据是否区分；实体的多个记录是否被错误拆到训练与测试两侧；相关性是否被写成因果；聚类是否有成员稳定性；预测驱动优化是否把响应不确定性传到决策；排名或权重是否有尺度、方向和扰动敏感性；所有题目要求的年份、类别和附件表是否完整输出。

图表以揭示数据证据和不确定性为目的，按任务选择分布图、校准/残差图、带区间的预测图、混淆矩阵、稳定性图或敏感性图。不要机械生成热力图、箱线图或特征重要性；一张图只在它回答明确问题时保留。

## 交接字段

分析报告须记录 `problem_track=A|B|C|content_override`、判定依据和所采用路线。代码结果须提供 `question_output_coverage`、`domain_audit` 和 `solution_evidence`。写作阶段逐项消费这些字段；任一题面输出为 `gap`，摘要不得写成已完成。
