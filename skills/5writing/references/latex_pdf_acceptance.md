# CUMCM LaTeX/PDF 验收

仅在用户选择 LaTeX 或要求正式 CUMCM PDF 时读取。

## 交付门槛

- 由模板控制导言区、黑色标题、页边距和分页；Writer 只填写标题字段和正文片段。
- 运行两遍 XeLaTeX。缺文件、未定义命令、未解析引用或超过 3pt 的横向溢出均失败。
- 检查 A4 纵向页面、可提取中文、图片存在、唯一参考文献标题和生成元话语。
- 除首尾页外，正文版心纵向占用至少 60%；全页图表例外必须逐页视觉确认。
- 渲染全部页面，检查乱码、裁切、重叠、稀疏页、图表清晰度、页码和章节衔接。

## 同题优秀论文全文对标

仅当用户要求“优秀论文对标”“达到优秀论文水平”或基准复跑时启用；普通论文写作不设统一页数下限。

1. 选取2--5篇已核验的同年同题优秀论文，逐页查看全文，不能只看与当前争议相关的两问或若干截图。
2. 在 `reports/PAPER_BENCHMARK.md` 记录论文标识、来源核验、总页数、参考文献起始页、正文延伸页、附录/代码起始页，以及问题分析、算法、逐问结果、敏感性、评价和复现附录的覆盖情况。
3. 页数只用于发现“实验简报”式缺口。剔除封面、目录、参考文献和代码附录后，以已核验样本的正文下沿作为本题诊断门槛；不得把长代码附录计入正文，也不得为了越过门槛放大字号、行距、图片或强制分页。
4. 生成阶段不得读取或改写优秀论文的数值、图片和代码。只有己方结果冻结后，才用优秀论文检查结构、证据密度和阅读体验。
5. 若生成稿正文低于样本下沿，先建立“缺失证据清单”，只补充可复算的推导、算法、数值结果、验证、误差传递、局限或复现说明。若证据已经完整且表达更紧凑，须在验收报告中给出逐项覆盖矩阵，不能只写“篇幅虽短但完整”。
6. 每次实质修改后重新双遍编译、渲染全部页面并逐页检查。正文中任何内页占用不足60%、连续稀疏页或孤立浮动表页均失败；自然结束的末页可以留白，但仍须人工确认内容顺序正常。

验收报告至少记录：

```text
reference_papers: 2--5
reference_main_page_range: <min>--<max>
generated_main_text_pages: <n>
coverage_matrix: passed|failed
paper_depth: passed|failed
```

## 图表门槛

- 优先插入 PDF/SVG 矢量图，同时保留 300 DPI PNG 预览。
- 使用克制配色，并用线型、点型、纹理或直接标签保证灰度可辨。
- 图内不重复论文 caption，不用彩虹色、无意义 3D 图或装饰性图表。

在仓库环境中运行：

```bash
python skills/5writing/scripts/verify_latex_pdf.py paper \
  --render-dir tmp/pdfs/pages \
  --minimum-main-pages <由同题全文审计得到的正文下沿>
```

未启用优秀论文对标时省略 `--minimum-main-pages`。

脚本通过后仍须查看所有渲染页；自动检查不能代替视觉判断。
